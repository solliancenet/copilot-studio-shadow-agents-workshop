# Task 05-06 — Purview

## Introduction

Purview is a **data-classification** control. Sensitivity labels, auto-labeling, sensitive-information
types (like SSN) and data loss prevention act on the *data object itself* — the file, the record — not on
the connector or the identity. Keep three things apart:

- A label that **classifies** marks the file and is displayed. It doesn't stop Copilot Studio grounding on
  the file.
- A label that **encrypts** protects the file's content. Copilot Studio can't ground on a file with an
  encrypting label, even for users who can open it.
- A Purview **DLP policy** keyed on a label is a separate control. It acts on the locations and actions the
  policy names.

So what this control does to Scenario B depends on what the label enforces. This task tests how far that
holds, and names the two places classification does not reach.

## Description

You will inspect the `Confidential-PII` label on a pre-labeled copy of the leadership compensation file
(`Leadership/2026-comp-bands-labeled.xlsx`) and confirm the SSN sensitive-information type covers Customer
PII. Then you retest **Scenario B** (Benefits Buddy surfacing the comp file — the test is which copy it
cites as its source) and **Scenarios C/D** (Customer PII through Claims
Copilot's Dataverse connection), and record where labeling withholds the data versus where connector-level
access makes the label moot. You also note the one thing a label on a *file* can never stop: an
*instruction* hidden in grounding content, which is text, not classified data.

### 01: Inspect the label

<details markdown="block">
<summary>Expand this section for detailed steps</summary>

</details>

## Summary

Purview is the content-layer control. An encrypting label puts a file out of the agent's reach, so what it
does to Scenario B depends on what the label enforces. Against the PII in Scenarios C and D, a classification
doesn't re-authorize a connector read, and an injected instruction isn't data at all. Record the verdict and
remaining risk in the matrix.
